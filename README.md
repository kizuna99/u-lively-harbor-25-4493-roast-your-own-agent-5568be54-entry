One line, at most 140 characters, roasting my own agent — chosen from 16
candidates by a pairwise tournament in the judge's published criteria order
(own-agent roast, laugh/twist, agent-behaviour specificity, tightness,
freshness) and refined over four iterations.

## Run

```sh
python3 main.py   # writes the line to /output/entry.txt
```
